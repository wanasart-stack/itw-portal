# ระบบตรวจสอบผลการเรียน กศน. (ข้อมูลจาก ITW51)

เว็บไซต์แบบ static สำหรับวางบน GitHub Pages ให้นักศึกษาตรวจสอบข้อมูลของตนเองได้ ได้แก่ ชั่วโมง กพช. ผลการเรียนรายวิชา เกรดเฉลี่ย หน่วยกิต และวิชาเทียบโอน

- `index.html` คือหน้านักศึกษา
  - เข้าสู่ระบบด้วยรหัสนักศึกษา (10 หลักหรือ 20 หลักก็ได้)
  - รหัสผ่านคือเลขประจำตัวประชาชน หรือเลข G
- `admin.html` คือหน้าผู้ดูแลระบบ ใช้อัปโหลดไฟล์ ZIP จาก ITW51 เพื่ออัปเดตข้อมูล
- `data/` เก็บข้อมูลที่เข้ารหัสแล้ว หน้าผู้ดูแลเป็นผู้สร้างโฟลเดอร์นี้ ไม่ต้องแก้ไขเอง

ระบบนำขึ้นเฉพาะนักศึกษาที่ **กำลังศึกษาอยู่** ผู้ที่จบการศึกษาหรือพ้นสภาพแล้วจะไม่ถูกนำขึ้นระบบ

## การติดตั้ง (ทำครั้งเดียว)

### 1. สร้าง repository
1. เข้า https://github.com แล้วกด **New repository**
2. ตั้งชื่อ เช่น `itw-portal` แล้วเลือก **Public**
   - GitHub Pages แบบฟรีใช้ได้กับ Public เท่านั้น
3. เลือก **Add a README file** แล้วกด **Create repository**

### 2. อัปโหลดไฟล์ของระบบ
1. ในหน้า repository กด **Add file › Upload files**
2. ลากไฟล์ `index.html`, `admin.html`, `.nojekyll`, `README.md` และโฟลเดอร์ `assets` ลงไป
3. กด **Commit changes**

### 3. เปิด GitHub Pages
1. ไปที่ **Settings › Pages**
2. ที่ Source เลือก **Deploy from a branch**
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้ URL ประมาณนี้ `https://<ชื่อบัญชี>.github.io/itw-portal/`
   - URL นี้คือหน้าที่ส่งให้นักศึกษา
   - หน้าผู้ดูแลอยู่ที่ `https://<ชื่อบัญชี>.github.io/itw-portal/admin.html`

### 4. สร้าง token สำหรับหน้าผู้ดูแล
1. ไปที่ https://github.com/settings/personal-access-tokens/new
2. ตั้งค่าดังนี้
   - **Repository access:** เลือก **Only select repositories** แล้วเลือก `itw-portal` เท่านั้น
   - **Permissions › Contents:** เลือก **Read and write**
3. กด **Generate token** แล้วคัดลอกเก็บไว้ GitHub จะแสดง token ให้เห็นครั้งเดียว

## การอัปเดตข้อมูล

1. ส่งออกข้อมูลจาก ITW51 เป็นไฟล์ ZIP ตามปกติ
2. เปิด `admin.html` ใส่ token แล้วกด **ทดสอบการเชื่อมต่อ**
3. ลากไฟล์ ZIP มาวาง ระบบจะแสดงจำนวนนักศึกษาที่จะนำขึ้น
4. กด **อัปเดตขึ้น GitHub**
   - ระบบใช้เวลาเข้ารหัสหลายนาที อย่าปิดหน้าเว็บระหว่างทำงาน
5. เมื่อขึ้นข้อความว่าเรียบร้อย รอประมาณ 1–10 นาที ให้ GitHub Pages อัปเดตหน้าเว็บ

**ทางเลือกกรณีไม่ต้องการใช้ token:** กด **ดาวน์โหลดโฟลเดอร์ data** แล้วแตกไฟล์ จากนั้นอัปโหลดโฟลเดอร์ `data` ขึ้น repository ผ่าน **Add file › Upload files**

## ความปลอดภัย

- ข้อมูลของนักศึกษาแต่ละคนถูกเข้ารหัส (AES-GCM, PBKDF2 100,000 รอบ) ด้วยรหัสนักศึกษาและเลขบัตรของคนนั้น
- ระบบไม่เก็บเลขประจำตัวประชาชนไว้ที่ใดเลย
- **ข้อจำกัด:** เลขบัตรประชาชนมีรูปแบบที่คาดเดาได้บางส่วน ผู้ที่ตั้งใจจริงอาจเดารหัสของนักศึกษาทีละคนได้ แต่ต้องใช้เวลามาก
- **ห้ามอัปโหลดไฟล์ ZIP ต้นฉบับจาก ITW51 ขึ้น repository**
- การอัปเดตแต่ละครั้งเพิ่มขนาด repository ประมาณ 7 MB

## วิธีคำนวณ (ควรให้งานทะเบียนตรวจสอบ)

- **เกรดเฉลี่ยสะสม:** ใช้ผลการเรียนที่ดีที่สุดของแต่ละวิชา ถ่วงด้วยหน่วยกิต
- **หน่วยกิตที่ได้:** นับวิชาที่ได้เกรด 1 ขึ้นไป หรือได้ "ผ" รวมกับวิชาเทียบโอน
- **เกณฑ์:** อ่านจาก `rule.dbf` ของแต่ละระดับ
  - นักศึกษาที่เข้าเรียนก่อนภาคเรียนที่ 2/2556 ใช้เกณฑ์ กพช. เดิม
- **สัญลักษณ์เกรด:** ข = ขาดสอบ, ม = ไม่มีสิทธิ์สอบ, ผ = ผ่าน, ว่าง = รอผล
