# ระบบตรวจสอบผลการเรียน กศน. (ข้อมูลจาก ITW51)

เว็บไซต์แบบ static สำหรับวางบน GitHub Pages ให้นักศึกษาตรวจสอบข้อมูลของตนเองได้ ได้แก่ ชั่วโมง กพช. ผลการเรียนรายวิชา เกรดเฉลี่ย หน่วยกิต และวิชาเทียบโอน

- `index.html` คือหน้านักศึกษา
  - เข้าสู่ระบบด้วยรหัสนักศึกษา (10 หลักหรือ 20 หลักก็ได้)
  - รหัสผ่านคือเลขประจำตัวประชาชน หรือเลข G
- `admin.html` คือหน้าผู้ดูแลระบบ ใช้อัปโหลดไฟล์ ZIP จาก ITW51 เพื่ออัปเดตข้อมูล
- `data/` เก็บข้อมูลที่เข้ารหัสแล้ว หน้าผู้ดูแลเป็นผู้สร้างโฟลเดอร์นี้ ไม่ต้องแก้ไขเอง

ระบบนำขึ้นนักศึกษาที่ **กำลังศึกษาอยู่** และ **ผู้ที่เพิ่งจบการศึกษา** ซึ่งเข้าดูได้อีก 1 ภาคเรียนหลังจบ
- "ภาคเรียนปัจจุบัน" คือภาคเรียนล่าสุดที่มีการลงทะเบียนใน ITW51
- ผู้ที่จบในภาคเรียนปัจจุบันหรือภาคเรียนก่อนหน้าจะถูกนำขึ้น
- เมื่อเริ่มภาคเรียนใหม่ (มีการลงทะเบียนภาคเรียนใหม่ใน ITW51) และอัปโหลดข้อมูล ผู้ที่จบนานกว่านั้นจะถูกนำออกเองโดยอัตโนมัติ
- ผู้ที่พ้นสภาพนักศึกษาจะไม่ถูกนำขึ้นระบบ

## การติดตั้ง (ทำครั้งเดียว)

### 1. สร้าง repository
1. เข้า https://github.com แล้วกด **New repository**
2. ตั้งชื่อ เช่น `itw-portal` แล้วเลือก **Public**
   - GitHub Pages แบบฟรีใช้ได้กับ Public เท่านั้น ถ้าเป็นแพ็กเกจที่เสียเงินจะเลือก Private ได้
3. เลือก **Add a README file** แล้วกด **Create repository**

### 2. อัปโหลดไฟล์ของระบบ
1. ในหน้า repository กด **Add file › Upload files**
2. ลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ลงไป ได้แก่ `index.html`, `admin.html`, `.nojekyll`, `README.md` และโฟลเดอร์ `assets`
   - ไฟล์ `.nojekyll` อาจถูกซ่อนในเครื่อง ถ้าหาไม่เจอให้ข้ามได้
3. กด **Commit changes**

### 3. เปิด GitHub Pages
1. ไปที่ **Settings › Pages**
2. ที่ Source เลือก **Deploy from a branch**
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้ URL ประมาณนี้ `https://<ชื่อบัญชี>.github.io/itw-portal/`
   - URL นี้คือหน้าที่ส่งให้นักศึกษา
   - หน้าผู้ดูแลอยู่ที่ `https://<ชื่อบัญชี>.github.io/itw-portal/admin.html`

### 4. สร้าง token สำหรับหน้าผู้ดูแล
1. ไปที่ https://github.com/settings/personal-access-tokens/new (Fine-grained token)
2. ตั้งค่าดังนี้
   - **Token name:** `itw-portal-admin`
   - **Expiration:** ตามต้องการ เช่น 1 ปี
   - **Repository access:** เลือก **Only select repositories** แล้วเลือก `itw-portal` เท่านั้น
   - **Permissions › Repository permissions › Contents:** เลือก **Read and write**
3. กด **Generate token** แล้วคัดลอกเก็บไว้ในที่ปลอดภัย GitHub จะแสดง token ให้เห็นครั้งเดียว

## การอัปเดตข้อมูล (ทำทุกครั้งที่ ITW51 มีข้อมูลใหม่)

1. ส่งออกข้อมูลจาก ITW51 เป็นไฟล์ ZIP ตามปกติ เช่น `ITW51DATA_040967.ZIP`
2. เปิด `admin.html`
   - ช่องชื่อบัญชีและ repository จะเติมให้อัตโนมัติ
   - ใส่ token แล้วกด **ทดสอบการเชื่อมต่อ**
3. ลากไฟล์ ZIP มาวาง ระบบจะแสดงจำนวนนักศึกษาที่จะนำขึ้น
4. กด **อัปเดตขึ้น GitHub**
   - ระบบจะเข้ารหัสข้อมูลทีละคน ใช้เวลาหลายนาที ขึ้นกับความเร็วเครื่อง
   - อย่าปิดหน้าเว็บระหว่างทำงาน
5. เมื่อขึ้นข้อความว่าเรียบร้อย รอประมาณ 1–10 นาที ให้ GitHub Pages อัปเดตหน้าเว็บ

**ทางเลือกกรณีไม่ต้องการใช้ token:** กด **ดาวน์โหลดโฟลเดอร์ data** แล้วแตกไฟล์ `itw-data.zip` จากนั้นอัปโหลดโฟลเดอร์ `data` ขึ้น repository ผ่าน **Add file › Upload files** ระบบจะแทนที่ไฟล์เดิมให้

## ความปลอดภัยและข้อควรรู้

- **ข้อมูลที่เข้ารหัส:** ข้อมูลของนักศึกษาแต่ละคนถูกเข้ารหัส (AES-GCM) ด้วยกุญแจที่สร้างจากรหัสนักศึกษาและเลขประจำตัวประชาชน/เลข G ของคนนั้น (PBKDF2 100,000 รอบ)
  - ไฟล์ใน `data/` จึงอ่านไม่ออกหากไม่รู้รหัสผ่าน
  - ระบบไม่เก็บเลขประจำตัวประชาชนไว้ที่ใดเลย
- **ข้อจำกัดของรหัสผ่าน:** รหัสผ่านคือเลขบัตรประชาชน ซึ่งมีรูปแบบที่คาดเดาได้บางส่วน ถ้า repository เป็น Public ผู้ที่ตั้งใจจริงและมีเครื่องประสิทธิภาพสูงอาจเดารหัสของนักศึกษาทีละคนได้ แต่ต้องใช้เวลามาก
  - ถ้าต้องการความปลอดภัยสูงขึ้น ให้ใช้ repository แบบ Private ร่วมกับแพ็กเกจ GitHub ที่รองรับ Pages แบบ Private
- **ไฟล์ต้นฉบับ:** ไฟล์ ZIP ต้นฉบับจาก ITW51 ถูกอ่านในเบราว์เซอร์ของผู้ดูแลเท่านั้น ไม่ถูกส่งขึ้น GitHub **ห้ามอัปโหลดไฟล์ ZIP ต้นฉบับขึ้น repository**
- **token:** เก็บไว้ในเบราว์เซอร์เฉพาะเมื่อเลือก "จำการตั้งค่า" ไม่ควรเลือกบนเครื่องที่ใช้ร่วมกัน
- **ขนาด repository:** การอัปเดตแต่ละครั้งเพิ่มขนาดประมาณ 5–10 MB ถ้าอัปเดตบ่อยมาก repository จะโตขึ้นเรื่อย ๆ
  - GitHub แนะนำให้ repository มีขนาดไม่เกิน 1 GB
  - ถ้าใกล้เต็ม ให้สร้าง repository ใหม่แล้วทำขั้นตอนติดตั้งซ้ำ

## วิธีคำนวณที่ใช้ (ควรให้งานทะเบียนตรวจสอบ)

- **เกรดเฉลี่ยสะสม:** คำนวณจากผลการเรียนที่ดีที่สุดของแต่ละวิชา ถ่วงด้วยหน่วยกิต
- **หน่วยกิตที่ได้:** นับวิชาที่ได้เกรด 1 ขึ้นไป หรือได้ "ผ" รวมกับวิชาเทียบโอน
  - แยกเป็นวิชาบังคับและวิชาเลือกตามข้อมูลรายวิชา
- **เกณฑ์หน่วยกิตและชั่วโมง กพช.:** อ่านจากไฟล์ `rule.dbf` ของแต่ละระดับ
  - นักศึกษาที่เข้าเรียนก่อนภาคเรียนที่ 2/2556 ใช้เกณฑ์ กพช. เดิม
- **สัญลักษณ์เกรด:** ข = ขาดสอบ, ม = ไม่มีสิทธิ์สอบ, ผ = ผ่าน, ช่องว่าง = รอผล
