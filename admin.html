อัปเดตข้อมูลนักศึกษา

อัปโหลดไฟล์ ZIP ที่ส่งออกจาก ITW51 ระบบจะอ่านและเข้ารหัสข้อมูลในเบราว์เซอร์นี้ แล้วบันทึกขึ้น GitHub แทนที่ข้อมูลเดิม

ข้อมูลที่ใช้อยู่ตอนนี้

กำลังโหลด…

1. เชื่อมต่อ GitHub

2. เลือกไฟล์ ZIP จาก ITW51

ลากไฟล์ ZIP มาวางที่นี่ หรือคลิกเพื่อเลือกไฟล์ เช่น ITW51DATA_040967.ZIP · ไฟล์ต้นฉบับไม่ถูกส่งไปที่ใด

ระบบอัปโหลดเฉพาะนักศึกษาที่ยังกำลังศึกษาอยู่ ผู้ที่จบการศึกษาหรือพ้นสภาพแล้วจะไม่ถูกนำขึ้นระบบ

3. บันทึกข้อมูล

ข้อมูลของนักศึกษาแต่ละคนถูกเข้ารหัสด้วยรหัสนักศึกษาและเลขประจำตัวประชาชน/เลข G ของคนนั้น ไฟล์ใน GitHub จึงอ่านไม่ออกหากไม่รู้รหัสผ่าน ระบบไม่เก็บเลขประจำตัวประชาชนไว้ Token ถูกส่งไปที่ api.github.com เท่านั้น
